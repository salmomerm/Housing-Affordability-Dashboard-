Housing Affordability & Racial Disparities Dashboard

Timeline: Sep – Dec 2025

Overview

A data analytics project built to surface housing affordability and racial disparity trends using public data sources. I engineered a reproducible ETL pipeline in R and SQL to retrieve, clean, and validate 10,000+ records from multiple public datasets, then analyzed the resulting dataset for affordability and disparity patterns across neighborhoods, turning the findings into clear, actionable recommendations for stakeholders.

What I did
Designed and built a reproducible ETL pipeline (R + SQL) to pull data from multiple public sources into a single clean dataset
Validated and cleaned 10,000+ records, handling missing data and inconsistencies across sources
Analyzed the dataset for housing affordability and racial disparity trends
Compiled findings into a stakeholder-facing report with recommendations
Tools

R  ·  SQL
